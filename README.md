# 🏅 Summer Olympics 2020 Gold Medal Analysis using Excel Power Query

## 📌 Project Overview

This project demonstrates how Excel Power Query can be used to extract, clean, and transform data from a website.

The dataset contains the Summer Olympics 2020 Gold Medal table extracted directly from the web.

---

## 📊 Objective

The objective of this project is to

- Import web data using Power Query
- Clean inconsistent data
- Remove unnecessary symbols
- Remove null values
- Create a Gold Medal Percentage column
- Prepare the data for reporting and analysis

---

## 🛠 Tools Used

- Microsoft Excel
- Power Query
- Web Data Import

---

## Data Cleaning Steps

The following transformations were performed:

- Imported data from a website
- Removed unnecessary columns
- Removed null values
- Removed special characters (*)
- Changed data types
- Added Gold Medal Percentage column
- Loaded cleaned data into Excel
